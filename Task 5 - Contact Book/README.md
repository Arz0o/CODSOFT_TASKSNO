# Contact Book

## Description

This is a Python-based Contact Book application that allows users
to store and manage contact information.

## Features

- Add new contacts
- View all saved contacts
- Search contacts by name or phone number
- Update contact details
- Delete contacts
- User-friendly menu
- Input validation

## Contact Information

Each contact contains:

- Name
- Phone Number
- Email
- Address

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python contact_book.py
