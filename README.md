# Rock Paper Scissors Game

## Description

This is a Python-based Rock Paper Scissors game where the user
plays against the computer. The computer randomly selects
Rock, Paper, or Scissors, and the program determines the winner.

## Features

- User can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Automatically determines the winner
- Displays the user's and computer's choices
- Tracks scores
- Tracks ties
- Allows the user to play multiple rounds
- Handles invalid input

## Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a tie

## Technologies Used

- Python
- Random module

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python rock_paper_scissors.py
