# Password Generator

## Description

This is a Python-based password generator that creates
random passwords according to the length specified by the user.

## Features

- User-defined password length
- Random password generation
- Uppercase and lowercase letters
- Numbers
- Special characters
- Input validation
- Option to generate multiple passwords

## Technologies Used

- Python
- Random module
- String module

## How to Run

Run the following command:

```bash
python password_generator.py
